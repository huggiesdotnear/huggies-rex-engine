# huggies-rex-engine

💩 near defi trading engine

bun/frontend

```sh
bun i
bunx prettier . --write
bun tsc --noEmit
bun run frontend/index.html
# bun build recursive
cd frontend && bun build ./**/*.html --outdir=../static --minify
```

rust/backend

```sh
cargo fmt
cargo check
cargo run
# cargo build
cargo build --release
./target/release/huggies-rex-engine
```
