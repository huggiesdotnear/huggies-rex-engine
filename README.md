# huggies-rex-engine

💩 rhea finance personal trading engine

```sh
cargo check
cargo fmt
# env
cp .env.example .env
source .env
# run
cargo run
# cargo build
cargo build --release
./target/release/huggies-rex-engine

# docs
cargo doc --no-deps
cargo doc --open
```
