# huggies-rex-engine

💩 near agentic engine

bun/frontend

```sh
bun i
bunx prettier . --write
bun tsc --noEmit
# bun build recursive
bun run build.ts
```

rust/backend

```sh
cargo fmt
cargo check
cargo run
# cargo build
cargo build --release
./target/release/huggies-rex-engine
```
