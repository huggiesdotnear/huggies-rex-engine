never ship broken code, always rebuild/restart the constainer and verify your changes on the live site.

BUT do not rebuild/restart the container for a MINIMAL backend code change that does not affect or change the ui in any noticable way. a pure refactor, a rename, a moved file, a comment, a doc, a backend-only logic change — these do not need a rebuild and restart. ask the user first if unsure, or if the change touches the frontend or the middleman in any way.
